# Guía para desarrolladores

Esta guía está dirigida a quienes desarrollan y mantienen la aplicación, a diferencia del resto de la documentación, orientada a los usuarios de negocio y auditores.

El código fuente se encuentra en el repositorio [`app-analisis-siniestralidad`](https://github.com/sebastobone/app-analisis-siniestralidad). Esta documentación, en cambio, vive en un repositorio independiente: [`app-analisis-siniestralidad-docs`](https://github.com/sebastobone/app-analisis-siniestralidad-docs).

## Contenido

- [Arquitectura](arquitectura.md): stack tecnológico y componentes principales de la aplicación.
- [Configurar entorno y ejecutar pruebas](entorno.md): cómo clonar el repositorio, instalar dependencias y correr las pruebas automatizadas.
- [Despliegue](despliegue.md): cómo se sirve y opera la aplicación en producción.
- [Contribución](contribucion.md): ramas, convenciones de commits, hooks y proceso de release.
